BK Flow

Plataforma SaaS para gestão de mídias sociais integrando IA para aprovação de conteúdo, calendário dinâmico e automações.

PapelEngenheiro Full Stack
Ano2024
CategoriaSaaS / Automação
StatusEm Produção

Contexto & Problema

Equipes de marketing digital frequentemente lidam com ferramentas fragmentadas para criação, aprovação e agendamento de conteúdo. O processo manual de redigir legendas, enviá-las para revisão em planilhas ou comunicadores e, após aprovação, agendá-las em outra plataforma resulta em perda de produtividade e quebra de fluxo.

Objetivo

Desenvolver uma plataforma SaaS centralizada (BK Flow) que unifica o calendário editorial, fluxos de aprovação com papéis distintos (RBAC) e publicação automatizada, potencializada por IA para suporte na geração de copy e ideias estruturadas.

Arquitetura & Tecnologias

O sistema foi desenhado para ser serverless-first, priorizando velocidade de entrega e escalabilidade.

  • Frontend: React, TypeScript, Vite. Estado global com Zustand, e estado assíncrono rigorosamente gerido via React Query.
  • Componentização: Tailwind CSS e Shadcn/UI para um design system focado em consistência visual.
  • Backend & Dados: Supabase servindo como API e banco relacional (PostgreSQL). Utilização extensiva de RLS (Row Level Security) para isolamento de dados (multi-tenant).
  • Automação: Edge Functions (Deno) para orquestrar publicações agendadas e chamadas externas.

Decisões Técnicas & Desafios

Um dos maiores desafios técnicos foi o estado do calendário editorial. Mudanças de data via drag-and-drop exigiam mutações otimistas (Optimistic Updates) para garantir que a UI fosse instantânea, mesmo antes da persistência no Supabase. A escolha do React Query solucionou conflitos de estado e cache de forma elegante.

Outro ponto crítico foi a modelagem multi-tenant. O esquema de banco foi desenhado para separar os dados de cada agência/cliente nativamente através do PostgreSQL RLS, garantindo que usuários comuns nunca acessem relatórios de times aos quais não pertencem, eliminando vulnerabilidades na camada de aplicação.

Conclusão

O BK Flow se consolidou como uma infraestrutura robusta, demonstrando como a união de uma modelagem de banco relacional sólida com as práticas mais modernas do ecossistema React (estado imutável e assíncrono) pode gerar uma experiência de classe mundial para o usuário final.
