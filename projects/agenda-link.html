Agenda Link

Sistema de agendamento focado em autônomos, utilizando gerenciamento rígido de conflitos e integrações com gateways de pagamento.

PapelEngenheiro Full Stack
Ano2023
CategoriaSaaS / Transacional
StatusEm Produção

Contexto & Problema

Profissionais autônomos gastam horas semanais organizando horários, lidando com no-shows e realizando cobranças manuais. Plataformas genéricas muitas vezes falham na flexibilidade de pagamentos locais ou carecem de regras de negócio personalizadas para o prestador de serviço brasileiro.

Objetivo

Criar uma plataforma de reservas sem fricção (Booking System) onde o cliente final consegue ver disponibilidades reais, reservar o horário mediante pagamento (Stripe) e receber notificações automatizadas (WhatsApp/Email), liberando totalmente a agenda do profissional.

Arquitetura & Tecnologias

  • Frontend: React (Vite), priorizando velocidade e componentes visuais de calendário de alta performance.
  • Banco de Dados: PostgreSQL através do Supabase. A escolha do Postgres é vital pela transacionalidade ACID e constraints rigorosas (evitar double-booking).
  • Serverless: Supabase Edge Functions invocadas durante o checkout para comunicar com a API da Stripe de maneira segura.

Decisões Técnicas & Desafios

O maior risco arquitetural em um sistema de reservas é o fenômeno da Concorrência (race conditions). Se dois clientes tentarem reservar o mesmo horário simultaneamente, o sistema não pode permitir ambas as gravações. Implementei travas a nível de banco (Table Constraints no PostgreSQL) e validações no servidor antes de instanciar a Intent de Pagamento, garantindo integridade 100%.

Conclusão

Agenda Link prova que SaaS focado no transacional não tolera estado global instável. O projeto consolida princípios sólidos de engenharia de software transacional misturado à comodidade visual das tecnologias modernas de frontend.
