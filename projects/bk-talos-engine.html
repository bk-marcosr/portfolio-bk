BK Talos Engine

Motor assíncrono construído para sustentar automações e APIs RESTful, garantindo resiliência em requisições de alto volume.

PapelBackend Engineer
Ano2024
CategoriaBackend / Orquestração
StatusEm Produção

Contexto & Problema

Sistemas baseados puramente em interface começam a falhar quando precisam lidar com tarefas em background de longa duração (Long-polling, webhooks pesados ou LLM generation que excedem os limites de Edge Functions). Foi necessário isolar um motor independente capaz de engolir tarefas assíncronas.

Objetivo

Desenvolver uma engine robusta (Backend) capaz de servir como middleware persistente, enfileirando requisições, orquestrando instâncias simultâneas de mensageria (Baileys para WhatsApp) e mantendo conexão vetorial constante com o Gemini da Google.

Arquitetura & Tecnologias

  • Base: Servidor nativo Node.js usando o framework Express para roteamento de webhooks e API REST.
  • Linguagem: TypeScript rigoroso (Strict mode) para garantir segurança e previsão nas interfaces JSON trafegadas.
  • Conectores: Biblioteca Baileys para abstrair os websockets do WhatsApp e Supabase para gravação atômica dos registros.
  • Processamento de Filas: Gestão local assíncrona para não estourar o limite de conexões ativas na porta do servidor.

Decisões Técnicas & Desafios

Lidar com o ecossistema do Baileys é notoriamente complexo devido à natureza efêmera dos sockets do WhatsApp. A arquitetura foi estruturada para que, se o websocket cair, o Engine capture o encerramento, persista o estado local no Supabase, e efetue uma reconexão (Backoff Exponencial) sem travar a thread principal da API do Express.

Conclusão

BK Talos Engine serve como espinha dorsal da operação de produtos de IA do portfólio. Demonstra uma transição madura entre desenvolvedor front-end que consome APIs para um engenheiro capaz de planejar e sustentar a infraestrutura da API em si sob pressão constante.
